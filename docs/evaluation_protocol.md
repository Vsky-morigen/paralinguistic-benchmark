# 评分规则

输入为数据集中的录音，输出为被测模型对副语言信息的判断。程序直接比较模型回答与人工验证的参考标签，无需外部评分证据文件。

## 任务设置

- 声音性别、情绪、语速：音频＋问题＋类别选项，返回一个标签。
- 情境意图：音频＋问题＋同一台词对应的不同意图，返回一个情境描述。
- 重音、停顿：音频＋无标记台词，返回位置数组。属于有文字辅助的定位任务；不得与仅音频的端到端任务混报。

台词经 Unicode NFKC 规范化，去掉标点、重音及停顿标记。模型请求不含参考标签、正确选项索引、原录后标注或盲听者答案。分类选项顺序按固定种子打乱，与正确答案无关。

## 指标

| 维度 | 分数 | 全对条件 |
|---|---|---|
| 声音性别、情绪、语速、情境意图 | 标签匹配为 1，否则为 0 | 与参考标签一致 |
| 重音 | 规范化字符位置 F1 | 重音位置集合完全相同 |
| 句内停顿 | 文本边界位置 F1 | 排除句间及首尾边界后集合完全相同 |

声音性别描述听感。语速参考标签的 `speed_verified` 为 false 时不评分；验证后还须使用候选集合中明确的类别定义。

重音区间 `[start,end)` 从 0 开始，左闭右开，展开为字符位置集合。停顿位置为停顿前的规范化字符数。坐标规范化使用 Unicode NFKC、保留字母数字、转小写；中英文均为字符坐标，英文不按词计分。

设正确位置数为 TP、多标数为 FP、漏标数为 FN：

`精确率 = TP / (TP + FP)`

`召回率 = TP / (TP + FN)`

`F1 = 2TP / (2TP + FP + FN)`

重复、重叠位置只计一次。10 个字符中有 2 个应强调，把全句标为重音的 F1 为 1/3。只有一方为空时 F1 为 0；双方都明确为空时精确率、召回率、F1 均为 1。参考未知时不评分。位置数组缺失或无效时记 0，不能按“无重音／无停顿”处理。

停顿排除 `provenance.sentence_boundaries`、0 和文本末尾边界。相邻但不同的句内位置分别计误报和漏报，不使用时间容差，不对停顿时长评分。

## 分母与报告

- `scored`：已比较模型回答，包括记为 0 的拒答、漏答、格式错误。
- `error`：调用失败、音频缺失、内容或绑定校验错误。单列计数，按 0 计入有效题目的主分数。
- `skipped`：参考未知、语速未验证、维度关闭或模拟回答，不纳入有效题分母。

报告按维度、中文、英文及全部样本分别统计。`mean_score` 为主分数，以全部有效题目为分母；重音和停顿先算每条 F1 再平均。`pass_rate` 为全部有效题目的完全正确比例。`coverage` 为有效题目中已完成评分的比例。`completed_mean_score` 仅统计已评分回答，必须连同覆盖率使用。

类别任务另给已评分回答的 `completed_macro_f1`；重音、停顿另给平均精确率、召回率及逐条 TP／FP／FN。不输出跨维度总分。

## 可复现性

每次运行冻结音频副本、题目、标签、候选集合、模型参数、提示版本及内容校验值。续跑只复用绑定相同输入且完整的回答。模型回答或输入音频更改后必须重新评分，报告会拒绝使用过期结果。旧语音生成任务的运行记录不能作为理解任务评分。

建议使用相同台词的不同表达样本，并增加只给文字的对照实验，以检查模型是否依赖语气、重音、停顿，而不是从文字猜答案。
